**Checkpoint64 automatically backs up your game saves and keeps every version, so a corrupted, overwritten, or mod-broken save is one click from being restored.** It ships with presets for 140+ games and 7 emulators, so it already knows where each save folder lives.

Every game below has a save file location page with the exact folder path per platform. The most-asked-about games also have an in-depth guide — where the saves live, [how they break](../blog/anatomy-of-a-save-corruption/), and how to roll them back.

Some games have no save file at all — a competitive shooter keeps your progress on the publisher's servers, and what sits on your disk is the config: keybinds, sensitivity, video settings, HUD layout. Those get an entry too, pointed at the settings folder rather than a save folder. See the [game config backup guide](../game-config-backup/) for what's covered, including 16 dedicated servers.

Don't see your game? If it writes its save to a folder on disk, Checkpoint64 can back it up; point it at the folder and go.
