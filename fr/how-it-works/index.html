Checkpoint64 vérifie votre dossier toutes les 60 secondes. Quelque chose a changé ? Il attend que le jeu finisse d'écrire, puis envoie une nouvelle version tout seul. Seuls les fichiers modifiés sont transmis — le reste est ignoré.

UNDER THE HOOD

WHAT IT DOES WHILE YOU PLAY.

IT NEVER LOCKS YOUR FILES.

If the game is mid-save it waits for things to go quiet and tries again — no broken files, no stutter.

IT NAPS BETWEEN CHECKS.

One look at the folder every 60 seconds, then back to sleep. You won’t notice it while playing.

ONLY CHANGED FILES GO UP.

Renamed files cost nothing extra. A 500 MB world re-uploads as a few MB after a normal session.

RESTORE NEVER LOSES YOUR PLACE.

The version you restore from stays in history, so rolling back never costs you where you were.

IT WATCHES THE FOLDER, NOT THE GAME.

Steam, GOG, Epic, an emulator — it doesn’t care which launcher put the game there.

SAVE FILES ONLY.

It never touches games or ROMs. Pick which files count and skip the screenshots.

QUESTIONS FRÉQUENTES.

ALL QUESTIONS →
QU'EST-CE QUI COMPTE COMME « SAUVEGARDE » ?
Tout ce que votre jeu écrit sur votre disque dur. Checkpoint64 traite les fichiers d'un dossier comme une seule sauvegarde et les protège ensemble. Des préréglages pour 140+ jeux (et sept émulateurs) font la configuration pour vous ; pour le reste, pointez le dossier et choisissez les fichiers vous-même.
ENVOYEZ-VOUS PENDANT QUE LE JEU TOURNE ?
Oui, avec précaution. Checkpoint64 ne verrouille jamais vos fichiers. Il vérifie le dossier toutes les 60 secondes ; si le jeu est en train de sauvegarder, il attend que ça se calme et réessaie — aucun fichier corrompu, aucune saccade. L'appli somnole entre deux vérifications : vous ne la remarquerez pas en jouant.
ÇA MARCHE AVEC LES ÉMULATEURS OU LES SAUVEGARDES CONSOLE ?
Les émulateurs, carrément — RetroArch, Dolphin, PCSX2, DuckStation, PPSSPP, RPCS3 et Cemu ont tous leur préréglage : vos save states ont enfin un vrai historique de versions. Les sauvegardes console ne marchent que si vous les amenez d'abord sur un PC. L'appli elle-même tourne sur Windows, macOS (Apple Silicon) et Linux.
