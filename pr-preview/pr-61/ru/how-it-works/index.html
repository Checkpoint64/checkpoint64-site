UNDER THE HOOD

WHAT IT DOES WHILE YOU PLAY.

IT NEVER LOCKS YOUR FILES.

If the game is mid-save it waits for things to go quiet and tries again — no broken files, no stutter.

IT NAPS BETWEEN CHECKS.

One look at the folder every 60 seconds, then back to sleep. You won’t notice it while playing.

ONLY CHANGED FILES GO UP.

Renamed files cost nothing extra. A 500 MB world re-uploads as a few MB after a normal session.

RESTORE NEVER LOSES YOUR PLACE.

The version you restore from stays in history, so rolling back never costs you where you were.

IT WATCHES THE FOLDER, NOT THE GAME.

Steam, GOG, Epic, an emulator — it doesn’t care which launcher put the game there.

SAVE FILES ONLY.

It never touches games or ROMs. Pick which files count and skip the screenshots.

ЧАСТО СПРАШИВАЮТ.

ALL QUESTIONS →
ЧТО СЧИТАЕТСЯ «СОХРАНЕНИЕМ»?
Всё, что игра пишет к тебе на диск. Checkpoint64 считает файлы в папке одним сохранением и бэкапит их вместе. Для 140+ игр (и семи эмуляторов) есть готовые пресеты; для всего остального укажи папку и отметь нужные файлы сам.
ВЫ ГРУЗИТЕ ФАЙЛЫ, ПОКА ИГРА ЗАПУЩЕНА?
Да, аккуратно. Checkpoint64 никогда не блокирует твои файлы сохранений. Он проверяет папку каждые 60 секунд; если игра в этот момент пишет, ждёт тишины и пробует снова — никаких битых файлов и просадок. Между проверками приложение спит, так что в игре ты его не заметишь.
ЭТО РАБОТАЕТ С ЭМУЛЯТОРАМИ И КОНСОЛЬНЫМИ СЕЙВАМИ?
С эмуляторами — конечно: у RetroArch, Dolphin, PCSX2, DuckStation, PPSSPP, RPCS3 и Cemu есть пресеты, так что у твоих сейв-стейтов наконец появится нормальная история версий. Консольные сохранения работают, только если их сначала получится вытащить на ПК. Само приложение работает на Windows, macOS (Apple Silicon) и Linux.
