Game Save File Locations & Backup Guides

Checkpoint64 automatically backs up your game saves and keeps every version, so a corrupted, overwritten, or mod-broken save is one click from being restored. It ships with presets for 140+ games and 7 emulators, so it already knows where each save folder lives.

Every game below has a save file location page with the exact folder path per platform. The most-asked-about games also have an in-depth guide — where the saves live, how they break, and how to roll them back.

Don't see your game? If it writes its save to a folder on disk, Checkpoint64 can back it up; point it at the folder and go.

In-depth backup guides

How saves break in each of these games, and how to roll one back.

  • Skyrim

    Skyrim Special Edition saves live in one folder and one bad mod change can brick them. Checkpoint64 keeps every version of your .ess saves so a broken load order is one click from undone. Free download.

  • Minecraft

    A single corrupted region file can wipe a Minecraft world you've built for months. Checkpoint64 backs up your saves folder automatically and keeps every version, so a broken chunk is one click from restored. Free download for Windows, macOS, and Linux.

  • Satisfactory

    Satisfactory factories represent hundreds of hours, and a bad redesign or a corrupted autosave can undo them. Checkpoint64 keeps every version of your .sav files so you can experiment and roll back. Free download.

  • Valheim

    Valheim keeps each world as a .db and .fwl pair, and co-op groups constantly lose track of the newest copy. Checkpoint64 keeps every version with version locks, so one canonical world moves forward. Free download for Windows, macOS, and Linux.

  • Stardew Valley

    Stardew Valley's Steam Cloud sync can force a blind choice between two conflicting saves, and a bad SMAPI mod update can break the one you keep. Checkpoint64 keeps every version of your farm so you're never guessing. Free download for Windows, macOS, and Linux.

  • Elden Ring

    Elden Ring's Steam Cloud sync has a well-documented history of corrupting saves, and there's no official way to undo New Game+. Checkpoint64 keeps every version of your .sl2 so a bad sync or a big commitment is one click from undone. Free download.

  • Palworld

    Palworld's Level.sav only grows as your world ages, and a crash or bad shutdown mid-save is a well-known way to corrupt it. Checkpoint64 keeps every version so a bad save is one click from restored. Free download.

  • Factorio

    A 200-hour Factorio base is one bad mod update or one crashed autosave away from gone. Checkpoint64 keeps every version of your save — megabases included — so a disaster is one click from undone. Free download for Windows, macOS, and Linux.

  • Don't Starve Together

    Don't Starve Together runs a hidden server even when you play solo, and a crash mid-autosave can corrupt the world you've survived hundreds of days in. Checkpoint64 keeps every version so a bad save is one click from restored. Free download for Windows, macOS, and Linux.

  • 7 Days to Die

    7 Days to Die saves routinely stop working across major version updates, and a corrupted region can cost a horde-night base. Checkpoint64 keeps every version so an update or a bad region is one click from undone. Free download for Windows, macOS, and Linux.

  • Sons of the Forest

    Sons of the Forest keeps one live save per world, and whoever's hosting is the only copy that matters. Checkpoint64 keeps every version so a crash or a bad session doesn't cost the base you've built. Free download.

  • Enshrouded

    Enshrouded supports an official dedicated server for full-time co-op, but Checkpoint64 covers most of the same need for a small group at a fraction of the cost — plus version history a rented server doesn't give you. Free download.

  • Baldur's Gate 3

    Honour Mode keeps a single save that overwrites itself, and a mid-run mod change can break a 100-hour campaign. Checkpoint64 keeps every version of your BG3 profile folder, so a wipe or a broken load order is one click from undone. Free download.

  • Cyberpunk 2077

    Cyberpunk saves grow with the playthrough, and an update that invalidates your mod list can leave a long run unloadable. Checkpoint64 keeps every version of the save folder, so a broken load or a point of no return is one click from undone. Free download.

  • RimWorld

    A RimWorld save records the mod list that built the colony, so removing or updating a mod mid-run can leave a save that won't load. Checkpoint64 keeps every version of the Saves folder, so a broken load order or a dead colony is one click from undone. Free download.

  • Project Zomboid

    Zomboid deletes your character on death by design, and a crash mid-write can take the whole save with it. Checkpoint64 keeps every version of the Zomboid folder and adds a shared lock for co-op worlds, so a bite or a bad write is one click from undone. Free download.

  • Terraria

    Terraria writes a single .bak beside each world and overwrites it on the next save, so its safety net covers one bad write and nothing older. Checkpoint64 keeps every version of the Worlds folder, so a damaged world is one click from undone. Free download.

  • No Man's Sky

    No Man's Sky ships large updates that change how saves are written, and its own save slots rotate. Checkpoint64 keeps every version of your NMS folder, so a bad update or an expedition slot you overwrote is one click from undone. Free download.

  • Stellaris

    Ironman keeps one save that overwrites itself, and a DLC or mod update mid-campaign can leave a 400-year game unloadable. Checkpoint64 keeps every version of your save games folder, so a lost empire is one click from undone. Free download.

  • Kingdom Come: Deliverance II

    KCD2 rations manual saves on purpose, so the gap between your last save and now can be an hour of progress. Checkpoint64 keeps every version of the save folder, so a crash or a bad run is one click from undone. Free download.

  • S.T.A.L.K.E.R. 2

    S.T.A.L.K.E.R. 2 keeps saves in a different folder per store — Steam, EOS or GOG — so backup advice written for one copy misses the others. Checkpoint64 knows all three and keeps every version. Free download.

  • Subnautica 2

    Subnautica 2 supports co-op, so a group shares one world — and a game still receiving updates can change what a save has to contain. Checkpoint64 already knows the save path and keeps every version, with a lock so nobody overwrites the run. Free download.
