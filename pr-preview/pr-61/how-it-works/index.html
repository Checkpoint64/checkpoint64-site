FLIP AUTO ON

Checkpoint64 checks your save folder every 60 seconds. If something changed, it waits for the game to finish writing, then uploads a fresh version on its own. Only the changed files get sent — the rest is skipped.

UNDER THE HOOD

WHAT IT DOES WHILE YOU PLAY.

IT NEVER LOCKS YOUR FILES.

If the game is mid-save it waits for things to go quiet and tries again — no broken files, no stutter.

IT NAPS BETWEEN CHECKS.

One look at the folder every 60 seconds, then back to sleep. You won’t notice it while playing.

ONLY CHANGED FILES GO UP.

Renamed files cost nothing extra. A 500 MB world re-uploads as a few MB after a normal session.

RESTORE NEVER LOSES YOUR PLACE.

The version you restore from stays in history, so rolling back never costs you where you were.

IT WATCHES THE FOLDER, NOT THE GAME.

Steam, GOG, Epic, an emulator — it doesn’t care which launcher put the game there.

SAVE FILES ONLY.

It never touches games or ROMs. Pick which files count and skip the screenshots.

ALL QUESTIONS →
WHAT COUNTS AS A 'SAVE'?
Whatever your game writes to your hard drive. Checkpoint64 treats the files in a folder as one save and backs them up together. Presets for 140+ games (and seven emulators) set this up for you; for anything else, point at the folder and pick the files yourself.
DO YOU UPLOAD WHILE THE GAME IS RUNNING?
Yes, carefully. Checkpoint64 never locks your save files. It checks the folder every 60 seconds; if the game is mid-save it waits for things to go quiet and tries again — no broken files, no stutter. The app naps between checks, so you won’t notice it while playing.
DOES THIS WORK FOR EMULATORS OR CONSOLE SAVES?
Emulators, absolutely — RetroArch, Dolphin, PCSX2, DuckStation, PPSSPP, RPCS3, and Cemu all have presets, so your save states finally get real version history. Console saves only work if you can get them onto a PC first. The app itself runs on Windows, macOS (Apple Silicon), and Linux.
