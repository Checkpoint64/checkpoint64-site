Three steps, once. After that you never think about save files again — which is the whole point.

Toma una instantánea de tu carpeta de guardado y envía una copia a la nube. Cada subida se convierte en su propia versión con nombre — la versión uno de muchas.

02 · AUTO-BACKUP

ACTIVA EL AUTO

Checkpoint64 revisa tu carpeta cada 60 segundos. ¿Algo cambió? Espera a que el juego termine de escribir y sube una versión nueva por su cuenta. Solo se envían los archivos modificados — el resto se omite.

UNDER THE HOOD

WHAT IT DOES WHILE YOU PLAY.

IT NEVER LOCKS YOUR FILES.

If the game is mid-save it waits for things to go quiet and tries again — no broken files, no stutter.

IT NAPS BETWEEN CHECKS.

One look at the folder every 60 seconds, then back to sleep. You won’t notice it while playing.

ONLY CHANGED FILES GO UP.

Renamed files cost nothing extra. A 500 MB world re-uploads as a few MB after a normal session.

RESTORE NEVER LOSES YOUR PLACE.

The version you restore from stays in history, so rolling back never costs you where you were.

IT WATCHES THE FOLDER, NOT THE GAME.

Steam, GOG, Epic, an emulator — it doesn’t care which launcher put the game there.

SAVE FILES ONLY.

It never touches games or ROMs. Pick which files count and skip the screenshots.

PREGUNTAS FRECUENTES.

ALL QUESTIONS →
¿QUÉ CUENTA COMO «PARTIDA»?
Todo lo que tu juego escribe en el disco duro. Checkpoint64 trata los archivos de una carpeta como una sola partida y los respalda juntos. Los preajustes para 140+ juegos (y siete emuladores) lo configuran por ti; para cualquier otro, apunta a la carpeta y elige los archivos tú mismo.
¿SUBÍS MIENTRAS EL JUEGO ESTÁ ABIERTO?
Sí, con cuidado. Checkpoint64 nunca bloquea tus archivos. Revisa la carpeta cada 60 segundos; si el juego está guardando, espera a que haya calma y vuelve a intentarlo — sin archivos rotos, sin tirones. La app dormita entre revisiones: no la notarás mientras juegas.
¿FUNCIONA CON EMULADORES O PARTIDAS DE CONSOLA?
Con emuladores, totalmente — RetroArch, Dolphin, PCSX2, DuckStation, PPSSPP, RPCS3 y Cemu tienen preajuste, así que tus save states por fin tienen historial de versiones de verdad. Las partidas de consola solo funcionan si primero las llevas a un PC. La app corre en Windows, macOS (Apple Silicon) y Linux.
