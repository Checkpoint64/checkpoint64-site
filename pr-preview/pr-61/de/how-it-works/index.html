UNDER THE HOOD

WHAT IT DOES WHILE YOU PLAY.

IT NEVER LOCKS YOUR FILES.

If the game is mid-save it waits for things to go quiet and tries again — no broken files, no stutter.

IT NAPS BETWEEN CHECKS.

One look at the folder every 60 seconds, then back to sleep. You won’t notice it while playing.

ONLY CHANGED FILES GO UP.

Renamed files cost nothing extra. A 500 MB world re-uploads as a few MB after a normal session.

RESTORE NEVER LOSES YOUR PLACE.

The version you restore from stays in history, so rolling back never costs you where you were.

IT WATCHES THE FOLDER, NOT THE GAME.

Steam, GOG, Epic, an emulator — it doesn’t care which launcher put the game there.

SAVE FILES ONLY.

It never touches games or ROMs. Pick which files count and skip the screenshots.

HÄUFIG GEPRÜFT.

ALL QUESTIONS →
WAS ZÄHLT ALS „SPIELSTAND"?
Alles, was dein Spiel auf die Festplatte schreibt. Checkpoint64 behandelt die Dateien in einem Ordner als einen Spielstand und sichert sie gemeinsam. Vorlagen für 140+ Spiele (und sieben Emulatoren) richten das für dich ein; für alles andere zeigst du auf den Ordner und wählst die Dateien selbst.
LADET IHR HOCH, WÄHREND DAS SPIEL LÄUFT?
Ja, behutsam. Checkpoint64 sperrt deine Spielstand-Dateien nie. Es prüft den Ordner alle 60 Sekunden; speichert das Spiel gerade, wartet es, bis Ruhe ist, und versucht es erneut — keine kaputten Dateien, kein Ruckeln. Zwischen den Prüfungen döst die App, du merkst sie beim Spielen nicht.
FUNKTIONIERT DAS MIT EMULATOREN ODER KONSOLEN-SPIELSTÄNDEN?
Emulatoren, absolut — RetroArch, Dolphin, PCSX2, DuckStation, PPSSPP, RPCS3 und Cemu haben alle Vorlagen, deine Save-States bekommen also endlich echten Versionsverlauf. Konsolen-Spielstände funktionieren nur, wenn du sie erst auf einen PC bekommst. Die App selbst läuft auf Windows, macOS (Apple Silicon) und Linux.
